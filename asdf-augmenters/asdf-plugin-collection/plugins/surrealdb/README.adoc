=== Dependencies

* `+bash+`, `+curl+`, `+tar+`, and
https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX
utilities]

=== Install

Plugin:

[source,bash]
----
asdf plugin add surrealdb https://github.com/hyperpolymath/asdf-surrealdb-plugin.git
----

surrealdb:

[source,bash]
----
# Show all installable versions
asdf list-all surrealdb

# Install specific version
asdf install surrealdb latest

# Set a version globally (in your ~/.tool-versions file)
asdf global surrealdb latest

# Now surrealdb commands are available
surrealdb --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list surrealdb

# Set local version for current directory
asdf local surrealdb <version>

# Uninstall a version
asdf uninstall surrealdb <version>
----
