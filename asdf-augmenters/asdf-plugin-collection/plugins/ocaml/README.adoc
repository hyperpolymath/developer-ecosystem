=== Dependencies

* `+bash+`, `+curl+`, `+tar+`, and
https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX
utilities]

=== Install

Plugin:

[source,bash]
----
asdf plugin add ocaml https://github.com/hyperpolymath/asdf-ocaml-plugin.git
----

ocaml:

[source,bash]
----
# Show all installable versions
asdf list-all ocaml

# Install specific version
asdf install ocaml latest

# Set a version globally (in your ~/.tool-versions file)
asdf global ocaml latest

# Now ocaml commands are available
ocaml --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list ocaml

# Set local version for current directory
asdf local ocaml <version>

# Uninstall a version
asdf uninstall ocaml <version>
----
