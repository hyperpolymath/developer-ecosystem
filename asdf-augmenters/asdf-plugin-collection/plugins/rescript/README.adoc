https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX

=== Install

Plugin:

[source,bash]
----
asdf plugin add rescript https://github.com/hyperpolymath/asdf-rescript-plugin.git
----

rescript:

[source,bash]
----
# Show all installable versions
asdf list-all rescript

# Install specific version
asdf install rescript latest

# Set a version globally (in your ~/.tool-versions file)
asdf global rescript latest

# Now rescript commands are available
rescript --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list rescript

# Set local version for current directory
asdf local rescript <version>

# Uninstall a version
asdf uninstall rescript <version>
----
