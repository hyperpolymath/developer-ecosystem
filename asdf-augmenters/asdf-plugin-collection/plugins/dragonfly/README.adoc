=== Dependencies

* `+bash+`, `+curl+`, `+tar+`, and
https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX
utilities]

=== Install

Plugin:

[source,bash]
----
asdf plugin add dragonfly https://github.com/hyperpolymath/asdf-dragonfly-plugin.git
----

dragonfly:

[source,bash]
----
# Show all installable versions
asdf list-all dragonfly

# Install specific version
asdf install dragonfly latest

# Set a version globally (in your ~/.tool-versions file)
asdf global dragonfly latest

# Now dragonfly commands are available
dragonfly --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list dragonfly

# Set local version for current directory
asdf local dragonfly <version>

# Uninstall a version
asdf uninstall dragonfly <version>
----
