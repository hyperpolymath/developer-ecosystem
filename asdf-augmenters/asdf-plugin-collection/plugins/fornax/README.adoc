https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX
utilities]

=== Install

Plugin:

[source,bash]
----
asdf plugin add fornax https://github.com/hyperpolymath/asdf-fornax-plugin.git
----

fornax:

[source,bash]
----
# Show all installable versions
asdf list-all fornax

# Install specific version
asdf install fornax latest

# Set a version globally (in your ~/.tool-versions file)
asdf global fornax latest

# Now fornax commands are available
fornax --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list fornax

# Set local version for current directory
asdf local fornax <version>

# Uninstall a version
asdf uninstall fornax <version>
----
