https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX

=== Install

Plugin:

[source,bash]
----
asdf plugin add serum https://github.com/hyperpolymath/asdf-serum-plugin.git
----

serum:

[source,bash]
----
# Show all installable versions
asdf list-all serum

# Install specific version
asdf install serum latest

# Set a version globally (in your ~/.tool-versions file)
asdf global serum latest

# Now serum commands are available
serum --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list serum

# Set local version for current directory
asdf local serum <version>

# Uninstall a version
asdf uninstall serum <version>
----
