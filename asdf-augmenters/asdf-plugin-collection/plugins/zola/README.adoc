=== Dependencies

* `+bash+`, `+curl+`, `+tar+`, and
https://pubs.opengroup.org/onlinepubs/9699919799/idx/utilities.html[POSIX
utilities]

=== Install

Plugin:

[source,bash]
----
asdf plugin add zola https://github.com/hyperpolymath/asdf-zola-plugin.git
----

zola:

[source,bash]
----
# Show all installable versions
asdf list-all zola

# Install specific version
asdf install zola latest

# Set a version globally (in your ~/.tool-versions file)
asdf global zola latest

# Now zola commands are available
zola --version
----

Check https://asdf-vm.com/guide/getting-started.html[asdf] readme for
more instructions.

=== Usage

[source,bash]
----
# List installed versions
asdf list zola

# Set local version for current directory
asdf local zola <version>

# Uninstall a version
asdf uninstall zola <version>
----
