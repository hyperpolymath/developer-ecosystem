== Technical Architecture

**Implemented (app/Main.hs, src/Spindle/Registry.hs):**
[source,haskell]
----
-- CLI Commands:
--   spindle register <file.ncl>  - Register validated config
--   spindle list                 - List all registered configs
--   spindle get <name>           - Show config details
--   spindle remove <name>        - Remove from registry
--   spindle parse <file.ncl>     - Parse and validate

-- Pipeline:
parseAndValidate :: FilePath -> B.ByteString -> Either String Config
parseAndValidate filename content = do
  expr <- parseNickelFile filename content  -- 1. Parse .ncl
  evaluatedValue <- eval expr               -- 2. Evaluate with hnickel
  let jsonValue = nvalueToJSON evaluatedValue -- 3. Convert to JSON
  eitherDecodeStrict' jsonValue             -- 4. Decode to Haskell types
----

**Registry Module (Spindle.Registry):**
* `RegistryEntry` - Metadata storage (name, version, description, path, timestamp)
* `Registry` - Map-based storage with JSON persistence
* `RegistryError` - Typed errors (EntryNotFound, EntryAlreadyExists, etc.)
* Full CRUD operations: register, unregister, lookupEntry, listEntries
* Persistence: loadRegistry, saveRegistry (`.spindle/registry.json`)

**Future features:**
