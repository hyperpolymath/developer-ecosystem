Deno runtime interoperability bridges and tools.

== Projects

Deno integration layers for cross-runtime and cross-language interop:

* *beamdeno* — BEAM/Erlang ↔ Deno bridge (ETF serialisation, process messaging)
* *bundeno* — Bun ↔ Deno compatibility layer (fs, process shims)
* *deno-bunbridge* — Deno ↔ Bun bidirectional bridge (serve, spawn, file APIs)
* *v-deno* — V language ↔ Deno FFI bridge (native compilation, V library bindings)
