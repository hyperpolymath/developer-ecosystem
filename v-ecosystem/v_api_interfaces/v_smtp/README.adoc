= v_smtp
// SPDX-License-Identifier: CC-BY-SA-4.0

SMTP protocol types and server for the V-Ecosystem API interfaces layer.
Implements SMTP command processing, envelope handling, address validation,
and response formatting per RFC 5321.

Supports HELO/EHLO, MAIL FROM, RCPT TO, DATA, QUIT, RSET, VRFY, NOOP,
STARTTLS, and AUTH commands with extension negotiation.
