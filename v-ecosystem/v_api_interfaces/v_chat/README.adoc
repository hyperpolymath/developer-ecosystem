= v_chat
// SPDX-License-Identifier: CC-BY-SA-4.0

Real-time chat server types for the V-Ecosystem API interfaces layer.
Implements room management, message history, presence tracking, message
editing and deletion, and member management.

Supports Text, Image, File, System, Typing, and Read message types with
public and private rooms, message history retrieval, and online/offline
presence tracking.
