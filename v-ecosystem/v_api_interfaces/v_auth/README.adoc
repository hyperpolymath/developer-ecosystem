= v_auth
// SPDX-License-Identifier: CC-BY-SA-4.0

Authentication server protocol types for the V-Ecosystem API interfaces layer.
Implements multi-method authentication (Password, Token, Certificate, OAuth2, SAML,
WebAuthn, Kerberos), token issuance with claims, and password hashing via HMAC-SHA256.
Maps to `proven-servers/protocols/proven-authserver`.
