= v_stun
// SPDX-License-Identifier: CC-BY-SA-4.0

Session Traversal Utilities for NAT (STUN) message construction, XOR address
mapping, fingerprint computation, and binding request/response handling for the
V-Ecosystem API interfaces layer. Implements RFC 5389.
Maps to `proven-servers/protocols/proven-stun`.
