= v_container
// SPDX-License-Identifier: CC-BY-SA-4.0

OCI container management protocol types for the V-Ecosystem API interfaces
layer. Maps to `proven-servers/protocols/proven-container`.

Provides container lifecycle management (create, start, stop, remove, inspect),
image operations (pull, list), and a runtime abstraction that auto-detects
Podman, Docker, and containerd via their Unix socket paths. Supports port
mappings, volume mounts, environment variables, labels, restart policies,
and resource limits (memory, CPU).
