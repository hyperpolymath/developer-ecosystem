= v-mqtt
// SPDX-License-Identifier: CC-BY-SA-4.0

Minimal MQTT 3.1.1 client for the V-Ecosystem API interfaces layer.
Implements CONNECT, PUBLISH, SUBSCRIBE, UNSUBSCRIBE, PINGREQ, and DISCONNECT over raw TCP at QoS 0 (fire and forget), without external library dependencies.
Targets IIoT and SCADA edge telemetry scenarios where lightweight publish/subscribe messaging is needed and delivery guarantees are handled at the application layer.
