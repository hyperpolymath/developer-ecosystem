= v_pop3
// SPDX-License-Identifier: CC-BY-SA-4.0

POP3 protocol types and server for the V-Ecosystem API interfaces layer.
Implements message retrieval, deletion, stat, list, top, and unique-id
listing per RFC 1939.

Supports USER, PASS, STAT, LIST, RETR, DELE, NOOP, RSET, QUIT, TOP,
and UIDL commands with the standard Authorization/Transaction/Update
state machine.
