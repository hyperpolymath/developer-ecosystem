= v_mcp — Model Context Protocol for V
:toc:
:toclevels: 2

== Overview

`v_mcp` is the world's first V-lang implementation of the
https://modelcontextprotocol.io[Model Context Protocol (MCP)].
MCP is a JSON-RPC 2.0-based protocol that allows AI model hosts
(such as Claude Desktop, VS Code, and other LLM clients) to
discover and invoke tools, read resources, and retrieve prompt
templates from external servers.

This implementation maps directly to the Idris2 ABI defined at
`proven-servers/protocols/proven-mcp`, ensuring type-level
conformance with the formally verified protocol specification.

== Quick Start

[source,v]
----
import v_mcp
import json

fn main() {
    mut server := v_mcp.new_server('my-server', '1.0.0')

    mut schema := map[string]json.Any{}
    schema['type'] = json.Any('object')

    server.add_tool(
        v_mcp.ToolDefinition{
            name: 'greet'
            description: 'Returns a greeting'
            input_schema: schema
        },
        fn (params map[string]json.Any) !v_mcp.ToolResult {
            name := (params['name'] or { json.Any('world') }).str()
            return v_mcp.text_result('Hello, ${name}!')
        },
    )

    server.serve()!
}
----

== Architecture

[cols="1,3"]
|===
| File | Purpose

| `src/types.v`
| Protocol types: MessageType, Transport, ContentType, ErrorCode, Capability

| `src/jsonrpc.v`
| JSON-RPC 2.0 request/response/notification framing and parsing

| `src/transport.v`
| Content-Length header framing over stdio

| `src/server.v`
| McpServer core: capability negotiation, request routing

| `src/tools.v`
| Tool definition, handler dispatch, result types

| `src/resources.v`
| Resource definition and content serving

| `src/prompts.v`
| Prompt template definition and rendering

| `src/mcp.v`
| Module root with re-exports
|===

== Protocol Version

This implementation targets MCP protocol version *2025-03-26*.

== Transport

Currently supports **stdio** transport with Content-Length header framing:

----
Content-Length: 42\r\n
\r\n
{"jsonrpc":"2.0","id":"1","method":"ping"}
----

== ABI Mapping

The types in `src/types.v` correspond 1:1 with the Idris2 ABI at
`proven-servers/protocols/proven-mcp/src/Mcp/Types.idr`:

[cols="1,1"]
|===
| Idris2 ABI Type | V Type

| `MessageType` | `v_mcp.MessageType`
| `Transport` | `v_mcp.Transport`
| `ContentType` | `v_mcp.ContentType`
| `ErrorCode` | `v_mcp.ErrorCode`
| `Capability` | `v_mcp.Capability`
|===
