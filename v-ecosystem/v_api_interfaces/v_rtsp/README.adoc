= v_rtsp
// SPDX-License-Identifier: CC-BY-SA-4.0

RTSP protocol types and server for the V-Ecosystem API interfaces layer.
Implements streaming session management, transport negotiation, and
request/response handling per RFC 7826.

Supports DESCRIBE, ANNOUNCE, SETUP, PLAY, PAUSE, TEARDOWN, GET_PARAMETER,
SET_PARAMETER, RECORD, and OPTIONS methods with transport specification
parsing and session state management.
