= v-trpc
// SPDX-License-Identifier: CC-BY-SA-4.0

Type-safe RPC over HTTP for the V-Ecosystem API interfaces layer.
Provides a tRPC-inspired router where procedures are registered with explicit input validators and typed handler functions, enabling compile-time schema safety.
Supports queries (idempotent reads via GET/POST) and mutations (state changes via POST), with a composable middleware chain for cross-cutting concerns like authentication and logging.
