= v_irc
// SPDX-License-Identifier: CC-BY-SA-4.0

IRC protocol types and server for the V-Ecosystem API interfaces layer.
Implements user registration, channel management, message routing, topic
setting, and kick/ban operations per RFC 2812.

Supports NICK, USER, JOIN, PART, PRIVMSG, NOTICE, QUIT, PING, PONG,
MODE, TOPIC, KICK, BAN, WHO, WHOIS, and LIST commands with IRC message
prefix parsing and formatting.
