= v-webdav
// SPDX-License-Identifier: CC-BY-SA-4.0

WebDAV protocol connector for the V-Ecosystem API interfaces layer.
Implements Web Distributed Authoring and Versioning (RFC 4918) over HTTP/HTTPS.
Supports PROPFIND, PROPPATCH, MKCOL, COPY, MOVE, LOCK, UNLOCK, and standard GET/PUT/DELETE operations for remote file management against Nextcloud, Apache mod_dav, nginx-dav, and similar WebDAV servers.
