= v-snmp
// SPDX-License-Identifier: CC-BY-SA-4.0

SNMPv2c/v3 (RFC 3416/3414) network monitoring client for the V-Ecosystem API interfaces layer.
Supports GET, GETNEXT, GETBULK, SET, and WALK operations with BER-encoded ASN.1 PDUs.
Implements USM (User-based Security Model) for SNMPv3 authentication and privacy.
