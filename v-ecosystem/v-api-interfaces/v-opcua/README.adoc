= v-opcua
// SPDX-License-Identifier: CC-BY-SA-4.0

OPC UA protocol connector for the V-Ecosystem API interfaces layer.
Implements an OPC Unified Architecture (IEC 62541) client over TCP with UA Binary encoding.
Supports session management, node browsing, attribute read/write, method calls, and monitored item subscriptions for industrial automation, SCADA, and IIoT integration.
