== What Is Here

This directory contains all V-lang work produced in the hyperpolymath estate,
offered to the V community following the estate's decision to retire V-lang in
favour of Zig for systems-level FFI work (2026-04-10).

=== Structure

----
v-ecosystem/
├── TRANSFER.adoc         # Full transfer documentation (start here)
├── MIGRATION.adoc        # Migration notes: V stubs → Zig FFI
├── connectors/           # 11 service-connector stubs (V-lang client patterns)
├── v-api-interfaces/     # 95+ protocol scaffolds (hyphen naming)
│   ├── v-proven/         # Safe-operations library bindings (PMPL-1.0-or-later)
│   ├── v-bebop/          # Bebop binary serialisation bindings (AGPL-3.0-or-later)
│   └── ... (93 protocol scaffolds: WebSocket, gRPC, MQTT, REST, etc.)
├── v_api_interfaces/     # Additional protocol scaffolds (underscore naming)
│   ├── verisimdb_graphql/ # VeriSimDB GraphQL gateway pattern
│   ├── verisimdb_grpc/    # VeriSimDB gRPC gateway pattern
│   ├── verisimdb_rest/    # VeriSimDB REST gateway pattern
│   └── ... (additional protocol stubs)
├── v-grpc/               # gRPC-Web runtime + v-protoc stub generator
├── v-rest/               # Conventional REST server
├── v-graphql/            # GraphQL support
├── v-zig-ffi/            # Zig FFI seam layer (mandatory for all connectors)
├── v-idris-abi/          # Idris2 ABI verification layer
├── v-telemetry/          # OpenTelemetry / observability support
├── v-validator/          # Type-safe validation and schema enforcement
├── v-middleware/         # Authentication, CORS, common request handlers
├── v-benchmarks/         # Performance testing suite
└── v-deno/               # V ↔ Deno FFI bridge
----
