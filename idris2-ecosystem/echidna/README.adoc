== ECHIDNA - Extensible Cognitive Hybrid Intelligence for Deductive Neural Assistance

.ECHIDNA Logo
image::https://example.com/echidna-logo.png[ECHIDNA Logo]

*A universal theorem proving framework with massive vocabulary and
scalable prover integration.*

=== 🚀 Overview

ECHIDNA is a next-generation theorem proving system that combines: -
*6000+ mathematical and computational terms* in a comprehensive
vocabulary - *30+ theorem provers* with a scalable registry architecture
- *Intelligent prover recommendation* based on theorem content -
*Natural language understanding* for theorem interpretation -
*Context-aware proof synthesis* using vocabulary analysis

=== 🔧 Installation

==== Prerequisites

* Idris 2 (latest version)
* Git
* Make (optional, for Justfile)

==== Build from Source

[source,bash]
----
# Clone the repository
git clone https://github.com/hyperpolymath/echidna.git
cd echidna

# Build the system
just build

# Run tests
just test

# Run benchmarks
just bench
----

==== Using Just (Recommended)

[source,bash]
----
# Install just (https://github.com/casey/just)
curl --proto '=https' --tlsv1.2 -sSf https://just.systems/install.sh | bash -s -- --to /usr/local/bin

# Then use any just command
just build    # Build the system
just test     # Run tests
just bench    # Run benchmarks
just check    # Build + test + bench
just clean    # Clean build artifacts
----

==== Usage Example

[source,idris]
----
-- Create enhanced system with full vocabulary
system = defaultEnhancedSystem

-- Analyze a theorem
theorem = "For all x, the derivative of x squared is 2x"
enhanced = enhanceTheorem theorem system

-- Get recommendations
recommendedProvers = enhanced.recommendedProvers
bestProver = selectBestProver enhanced system.provers

-- Format the theorem
formatResult = formatTheorem enhanced system
----

=== 🤖 Prover System

==== Core Provers (Type-Safe)

10 well-known provers with full type safety: - Z3, CVC5 (SMT solvers) -
Agda, Coq (dependent type) - Lean 4/3 (theorem provers) - Isabelle
(higher-order logic) - Vampire, E (ATP systems) - TLC, Alloy (model
checkers)

==== Scalable Registry

Architecture that supports thousands of provers: - *Modular design*:
Each prover in separate module - *Dynamic registration*: Avoids compiler
limitations - *Categorized*: Organized by prover type -
*Priority-based*: Ranking system for recommendations

==== Intelligent Selection

[source,idris]
----
-- The system automatically:
1. Analyzes theorem text
2. Extracts vocabulary terms
3. Suggests appropriate categories
4. Recommends optimal provers
5. Provides confidence scores
----
