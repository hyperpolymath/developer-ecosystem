=== Becoming a Maintainer

==== Expert Contributor Path

[arabic]
. Make 10+ accepted contributions
. Demonstrate expertise in Zig, Rust, or Swift
. Receive nomination from Core maintainer
. Receive majority Core approval

==== Core Maintainer Path

[arabic]
. Serve as Expert contributor for 12+ months
. Make sustained, high-quality contributions
. Receive nomination from Core maintainer
. Receive unanimous Core approval

=== Responsibilities

==== All Maintainers

* Follow the Code of Conduct
* Respond to issues and MRs in reasonable time
* Document decisions
* Mentor new contributors

==== Core Maintainers Additionally

* Final merge authority on `+main+`
* Security vulnerability response
* Release management
* Governance decisions
