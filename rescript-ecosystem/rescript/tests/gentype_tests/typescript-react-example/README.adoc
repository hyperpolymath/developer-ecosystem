== typescript-react-example

This project was created with
https://github.com/facebookincubator/create-react-app[Create React App].

For the setup, run `+npm install+`. Make sure to build gentype.native,
as stated in the project root README.

=== Running the Project

[source,sh]
----
# Start the Reason watcher.
npm run start

# In another tab: start the TypeScript watcher.
npm run ts:watch
----
