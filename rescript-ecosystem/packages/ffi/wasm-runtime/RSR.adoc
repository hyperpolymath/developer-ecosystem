== RSR (Rhodium Standard Repository) Compliance

=== Overview

This project follows the *Rhodium Standard Repository (RSR)* framework
for building high-quality, production-ready open source software. RSR
defines comprehensive standards across 11 categories to ensure software
is secure, maintainable, documented, and community-friendly.

=== Current Compliance Status

*Tier*: Bronze (Target: Silver) *Score*: 85%+ (Target: 90%+) *Last
Checked*: 2025-01-22

Run `+just rsr-check+` to verify current compliance.
