= rescript-poly-core Roadmap
:toc:
:icons: font

This document outlines the development roadmap for `rescript-poly-core`, the foundation library for the Hyperpolymath ReScript ecosystem.

== Vision

`rescript-poly-core` aims to be the standard foundation for building type-safe, maintainable ReScript applications with first-class MCP (Model Context Protocol) support. It should provide everything needed to build production-quality applications without external runtime dependencies.

== Current Status

**Version: 0.1.0** - Initial Release

The library provides core functionality:

* [x] Result type extensions
* [x] Async/Promise utilities (retry, timeout, parallelLimit)
* [x] Structured JSON logging
* [x] Configuration management from environment
* [x] MCP Protocol types and builders
* [x] MCP Server infrastructure

== Future Directions

=== Under Consideration

These features are being evaluated for future releases:

* **Core.State** - Immutable state management primitives
* **Core.Stream** - Async iterator/stream utilities
* **Core.Codec** - Binary encoding/decoding helpers
* **MCP.Sampling** - MCP sampling request support
* **MCP.Roots** - Filesystem roots support
* **DB.Query** - Database query builder abstraction

=== Not Planned

These are explicitly out of scope:

* React/UI components (separate `poly-ui` package)
* ORM or database drivers (use Deno's ecosystem)
* Authentication/authorization (application-level concern)
* Encryption primitives (use WebCrypto)

== Versioning

This project follows https://semver.org/[Semantic Versioning]:

* **MAJOR**: Breaking API changes
* **MINOR**: New features, backwards compatible
* **PATCH**: Bug fixes, backwards compatible

Pre-1.0 releases may have breaking changes in minor versions.
