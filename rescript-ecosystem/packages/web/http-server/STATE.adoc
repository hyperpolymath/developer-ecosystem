== Working Features

* Start HTTP server on configurable port/hostname
* Handle GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS
* Parse request path, query params, headers, body
* Build text, JSON, HTML responses
* Standard error responses (400, 401, 403, 404, 500)
* Redirects (301, 302, etc.)
* Pattern-based routing with wildcards
* Middleware composition
* CORS with configurable origins
* Request logging

== Known Limitations

* Path parameters (`:id`) not yet supported
* No multipart form parsing
* No streaming body support
* No built-in rate limiting
* No compression
